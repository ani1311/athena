# Personal Agent

## Features

- Wake up time.
- Sleep time.
- Track what all I did yesterday.
- What all I want to get done today.
- Save things that are on my mind that I want to do sometime when I am free.
- Tell it I am free and can do some of these things.

## What all does it need to store?

- Daily log
  - A summary of the conversation
- Weekly log
- Monthly log
- Yearly log

## Flows

1) When day starts the agent:
    - Reminds me of my general goals.
    - Asks me anything special I need to do today.

2) Hourly check up, the agent:
    - Gets checkup on anything I got done

3) I can talk to the agent:
    - Tell it I completed a task.
    - Add a new task.
    - Tell it a new thing I found interesting that I want to do later.
    - Suggest me something from the things I found interesting.
    - Tell it DND for the next N hours.
